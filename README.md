Para utilizar este repositório siga o roteiro abaixo:

<br>
1. Clonar o repositório
git clone https://github.com/projeto-simbiosys/Database

cd Database

<br>
2. Arquivos disponíveis

/scripts – Scripts SQL de criação e inserção

/models – Diagramas e modelos do banco

/docker – Estrutura para subir o banco via Docker

README.md – Documento principal

<br>
3. Rodar o Banco via Docker (recomendado)

Certifique-se de ter o Docker instalado

Execute na raiz do projeto:

docker compose up -d


Para finalizar:

docker compose down
